An open-source MCP for your coding agent

Learn from the code
your AI just wrote.

After every commit, your agent draws the change as a system-design diagram and marks each concept it relies on, right where it lives.

Add the MCP to your agent
claude mcp add --scope user concepts -- npx -y concepts-mcp@latest
Open in Cursor

Needs Node.js 20+ and git. Paste into your terminal.

Then turn it on in a repository. Ask your agent, or run the setup yourself; it asks where diagrams go and how much each commit saves:

“Set up concept diagrams for this repo.” or npx -y concepts-mcp@latest init

What your agent gets.

Your agent does the thinking. The MCP gives it the workflow, the history and a renderer.

get_concepts_instructions

The workflow, so every commit is modeled the same way.

setup_concepts

Sets up or changes where diagrams go and how much each commit saves, with a picker.

get_unprocessed_commits

Commits without a diagram yet, with diffs sized to fit.

get_concept_library

Concepts already learned, so their notes are reused.

record_commit_concepts

Lays out and draws the diagrams, then updates the library.
