# Toggle buttons with aria-pressed

_concept · beginner_

A button that stays on or off announces its state to screen readers through aria-pressed="true"/"false"; CSS can style the pressed state from the same attribute.

**Learn more:**

- [MDN: aria-pressed](<https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-pressed>)
